# Квалификация входящих заявок

Прототип к тестовому заданию **AI Solutions Architect (Delivery & Automation)**, AI Business Lab.

Текст клиента на входе — строгий JSON на выходе:

```json
{
  "budget_status": "qualified | unqualified | needs_clarification",
  "project_scope_summary": "краткое описание задачи, до двух предложений",
  "red_flags": ["риски, видные прямо из текста"]
}
```

## Что здесь интересного

Смысл прототипа не в том, что модель умеет отвечать. Смысл в том, что её ответ
проверяется программой и не ломает процесс, когда модель ошиблась.

1. **Проверка ответа в коде, а не надежда на промпт.** Инструкция — это просьба.
   Гарантию даёт функция `validate()`: есть ли все ключи, допустимо ли значение
   статуса, список ли в `red_flags`.
2. **Один повтор с объяснением ошибки.** Если проверка не прошла, модель получает
   ответ о том, что именно было не так, и пробует ещё раз.
3. **Понятное поведение при отказе.** Если и повтор не помог, заявка помечается как
   требующая уточнения и уходит менеджеру. Процесс не встаёт и мусор дальше не идёт.
4. **Текст клиента отделён от инструкции.** Сообщение приходит отдельным сообщением
   и никогда не подмешивается в системный промпт. Это защита от попытки клиента
   переписать правила прямо в своём тексте.
5. **`temperature=0`** — оценка заявки должна быть воспроизводимой.

## Запуск

Без ключа API, чтобы посмотреть логику и работу проверки:

```bash
python3 qualify.py --demo
```

С реальной моделью:

```bash
pip install -r requirements.txt
export LLM_API_KEY=...            # любой OpenAI-совместимый ключ
python3 qualify.py lead_1.txt
```

Переменные окружения: `LLM_API_KEY`, `LLM_API_URL` (по умолчанию OpenAI),
`LLM_MODEL` (по умолчанию `gpt-4o-mini`).

## Файлы

| Файл | Что внутри |
|---|---|
| `system_prompt.md` | Системная инструкция |

| `lead_3.txt` | Заявка ниже минимального чека |

## Что это не покрывает

Прототип закрывает один участок — квалификацию. Поиск по базе знаний, сборка
черновика КП, запись в CRM и маскирование персональных данных в него намеренно
не входят: в схеме из основного документа это отдельные шаги, и собирать их до
того, как подтвердилась работа квалификации, преждевременно.
